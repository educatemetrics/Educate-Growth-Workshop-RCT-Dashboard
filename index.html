Commitment screening

A more detailed screening layer defined for the RCT survey — five probe questions that turn each anticipated barrier above into a scored (0–2) commitment signal, so screeners can prioritise rather than reject borderline youth. These questions are part of the same live Awareness/KYC intake form as everything else on this tab (not a separate later interview) — the numbers below are computed live from actual responses. The June pilot data behind some other panels on this dashboard never asked these questions, which is why they're new to the RCT.

Score by criterion

Youth Questions

What youth are actually asking at registration — sourced from the Awareness form's free-text "Please ask any questions you may have at this time?" field (qna_notes), recorded verbatim by the enumerator/mobiliser. Grouped into themes below to spot patterns worth addressing at scale (e.g. in the mobiliser talking points), with the original verbatim text always one click away.

How the theming works: a hand-built keyword ruleset, not NLP/AI — each question is assigned to the first theme whose keyword matches. Check "Other / uncategorised" periodically as keywords get refined against real questions.
